# 旬間 (SHUNKAN) ドキュメント

旬間（SHUNKAN）は、自分で決めた今だけの期間をRoomとして作り、やりたいこと、達成したこと、残り時間、写真を残す個人利用のWebアプリです。最初のデモでは「2026 夏」と「TechJam 2026」のRoomを使います。

このフォルダは、チームが同じ前提で開発を進めるための共通資料です。実装の進捗・担当・完了状況はGitHub Issueを正本とし、資料の要件や設計を実装完了の表明として扱いません。

## 作業の基本ルール

1. 作業前に`dev`を最新にする。
2. `dev`から自分の作業ブランチを作る。
3. 作業が終わったら`dev`宛てにPull Requestを出す。
4. `main`へのマージはリポジトリ管理者だけが行う。
