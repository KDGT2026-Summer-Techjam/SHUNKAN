# ユーザー導線

この資料は、旬間 (SHUNKAN) を使う人が「次に何をするか」を迷わないように、画面ごとの入口と出口を整理するためのものです。実装完了状況はGitHub Issueを正本とし、この資料だけで完了扱いにはしません。

## 導線の基本方針

- 最初にRoomを選ぶ。Task、撮影、アルバムは選択中Roomに紐づける。
- Roomホームでは、残り時間と「今を残す」を最優先に見せる。
- 下部ナビは、Room、タスク、撮影、アルバム、アカウントの移動に使う。
- Room未選択でタスク、撮影、アルバムを押した場合は、Room選択へ誘導する。
- 開催中Roomだけ記録や編集を許可する。終了済みRoomはアルバム中心の閲覧導線にする。

## 初回利用

```text
トップ
  ↓ はじめる
ログイン
  ├─ アカウントがある → ログイン
  └─ アカウントがない → 新規登録
        ↓
Room一覧
  ├─ 開催中Roomがある → Roomホーム
  └─ Roomがない → 新しいRoomを作る → Roomホーム
```

初回利用では、登録・ログイン後にすぐRoom一覧へ進める。Roomがない人には「新しいRoomを作る」を主導線にする。

## 通常利用

```text
Room一覧
  ↓ このRoomを開く
Roomホーム
  ├─ 今を残す → SHUNKAN-log保存 → Roomホームまたはアルバム
  ├─ タスク → Task追加・編集・完了 → Task一覧
  ├─ アルバム → 完了Task・SHUNKAN-log・写真を確認
  └─ Room管理 → Room名・期間の編集、削除
```

通常利用の主導線は、`Roomホーム → 今を残す` とする。Task管理は準備や整理、アルバムは振り返りの導線として扱う。

## Task完了から思い出を残す導線

```text
Task一覧
  ├─ 完了する
  │    ↓
  │  Taskを完了状態にする
  │    ↓
  │  必要に応じて今を残すへ誘導
  └─ 今を残す
       ↓
     関連Taskを選ぶ
       ↓
     写真とひとことを保存しながらTaskを完了
       ↓
     アルバムで振り返る
```

Taskを単に完了する導線と、写真・SHUNKAN-logと一緒に完了する導線を分けて考える。タスク完了時の演出は、保存成功後だけに出す。

## Room状態別の導線

| Room状態 | 主な入口 | 主な行き先 | 操作方針 |
| --- | --- | --- | --- |
| 開催前 | Room一覧、Roomホーム | Roomホーム、Room編集 | 記録追加はまだできない |
| 開催中 | Room一覧、下部ナビ | 今を残す、Task、アルバム | 作成・編集・削除・完了操作を許可する |
| 終了済み | Room一覧、Roomホーム | アルバム、過去のSHUNKAN-log | 閲覧専用にする |
| Room未選択 | 下部ナビ | Room一覧 | Room選択が必要なことを伝える |

終了済みRoomでは「今を残す」ではなく、アルバムで見返す導線を強くする。Additionalの振り返りログはMust完了後にだけ扱う。

## 下部ナビの役割

| ナビ | Room選択中 | Room未選択 |
| --- | --- | --- |
| Room | Room一覧へ戻る | Room一覧へ進む |
| タスク | 選択中RoomのTask一覧へ進む | Room選択を促す |
| 撮影 | 開催中なら今を残すへ進む | Room選択を促す |
| アルバム | 選択中Roomのアルバムへ進む | Room選択を促す |
| アカウント | プロフィールへ進む | プロフィールへ進む |

撮影ボタンは中央の主操作として扱う。ただし開催期間外は無効状態にし、記録できない理由が分かる表示にする。

## 画面ごとの主導線

| 画面 | 主目的 | 最優先アクション | 次に進む先 |
| --- | --- | --- | --- |
| トップ | アプリを始める | はじめる | ログイン |
| ログイン | 既存利用者が入る | ログイン | Room一覧 |
| 新規登録 | 新しい利用者が始める | 登録してはじめる | Room一覧 |
| Room一覧 | 期間を選ぶ・作る | 開催中Roomを開く | Roomホーム |
| Roomホーム | 現在地を見る | 今を残す | SHUNKAN-log作成 |
| 今を残す | 瞬間を保存する | この瞬間を保存する | Roomホームまたはアルバム |
| Task一覧 | やりたいことを整理する | Task追加、完了 | Task一覧、今を残す |
| アルバム | 期間を振り返る | 写真・ログを見る | 必要に応じて編集画面 |
| アカウント | 利用者情報を見る | ログアウト | ログイン |

## レビューで見ること

1. 初回利用者が、登録後にRoomを作る必要を理解できるか。
2. Roomホームで、残り時間と「今を残す」がすぐ見つかるか。
3. Task完了とSHUNKAN-log保存の関係が分かりやすいか。
4. Room未選択時に、なぜタスク・撮影・アルバムが使えないか分かるか。
5. 終了済みRoomで、編集できない理由とアルバム導線が分かるか。
6. 下部ナビだけで主要画面を行き来できるか。
