# プロダクト方針：旬間 (SHUNKAN)

## ひとことで

旬間 (SHUNKAN) は、期限を自分で決めた今だけの期間を秒単位で数えながら、やりたいこと・達成したこと・その瞬間を自分のために残す、スマートフォン向けの個人利用 Web アプリです。

夏休みの終わりに何をしたんだろうと思うのではなく、日々の小さな行動や写真を残して、その期間を楽しめた実感をつくります。最初のデモは2026 夏と TechJam 2026を対象にしますが、文化祭まで、旅行までなどにも広げられます。

## 解決したいこと

- やりたいことは思い付くが、日常に流されて忘れてしまう。
- 大きな目標だけだと手を付けにくく、達成感を得にくい。
- 写真は残っても、そのときの気持ちや行動をあとから思い出しにくい。
- 残り時間と、すでに楽しめたことをひと目で振り返りたい。

## 想定する利用者

夏休みや学校行事をもっと充実させたい学生・若者。スマートフォンで、移動中や出来事の直後に短時間で使うことを主に想定します。

### ペルソナ

- 名前：佐藤 みなみ、20歳、大学2年生
- 状況：夏休みは友人との外出、アルバイト、帰省で予定が散らばり、やりたいことを後回しにしがち。
- 困りごと：行きたいイベントや食べたいものを忘れる。写真は残るが、そのときの気持ちや達成した実感はあとから思い出しにくい。
- 求めること：スマホで短く記録でき、期限と進捗を見ることで今のうちにやろうと思えること。

## 利用イメージ

1. 2026 夏などの個人用ルームを開き、そのルームの終了日時までの残り日・時・分・秒を見る。
2. 花火を見る、かき氷を食べるなど、そのルームで達成したいことをタスクとして登録する。
3. 今を残す画面で、出来事や気持ちをSHUNKAN-logとして残し、必要なら写真と写真へのひとことを添える。
4. タスクを完了にし、進捗率と完了数の変化を見る。
5. ルームのアルバムで、完了タスク、SHUNKAN-log、写真を時系列で振り返る。

## MVPの機能

- Django標準Authによる登録、ログイン、ログアウト
- ルームの作成・切替
- ルームごとに独立した秒単位カウントダウン
- ルーム内タスクの登録、完了、進捗表示
- SHUNKAN-log、写真、写真へのひとこと
- 完了タスク・記録・写真を並べるルームのアルバム

終了後の振り返りログ、写真EXIFの撮影日時、位置情報、公開・共有・SNS連携・他ユーザーからのコメントは、Must完了後または将来の対象です。

## 技術方針

- バックエンドはDjangoを採用する。
- 認証はDjango標準Authを使い、独自のパスワード実装は行わない。
- データベースは、開発・公開ともにPostgreSQLを基本方針とする。
- 写真本体はDBではなくストレージに保存する。開発中はmediaフォルダ、公開時は画像ストレージを使う。
- フロントエンドはDjango Templates とHTML/CSS、必要最小限のJavaScriptで作る。
- Tailwind CSSは今回導入せず、Figma由来のデザイントークンと共通CSSで統一する。
