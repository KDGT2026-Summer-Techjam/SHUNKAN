# 旬間 (SHUNKAN) 要件定義

## 目的

旬間（SHUNKAN）は、利用者が自分で決めた今だけの期間をRoomとして作り、終了時刻までを秒単位で数えながら、やりたいこと、達成したこと、その瞬間の記録と写真を残すスマートフォン向けの個人利用Webアプリです。

最初のデモでは、次の2つのRoomを用意します。

| Room | 終了日時 |
| --- | --- |
| 2026 夏 | 2026-08-31 23:59:59 JST |
| TechJam 2026 | 2026-08-28 18:00:00 JST |

## MVPの前提

- MVPでも利用者はユーザー登録・ログイン・ログアウトを行い、自分のRoomとデータだけを閲覧・編集する。
- Roomは個人用であり、共有、公開、共同編集、SNS連携、通知はMVP外とする。
- 各Roomは名前、開始日時、終了日時を持ち、終了日時までを秒単位で数える。
- 開発・テストのデータベースはPostgreSQL必須であり、SQLiteフォールバックは採用しない。
- 実装の進捗と担当はGitHub Issueを正本とする。この資料のMustは実装完了を意味しない。

## Must機能

### ログインとRoom

利用者はユーザー登録、ログイン、ログアウトを行う。ログイン後は、自分が作成したRoomだけを操作できる。

Roomには、少なくとも名前、開始日時、終了日時を設定する。Roomを切り替えると、そのRoom固有の終了日時、進捗、Task、記録を表示する。

### 秒単位カウントダウン

選択中Roomの終了日時までの残り日、時、分、秒を1秒ごとに更新して表示する。終了後は`00日 00:00:00`に固定し、期間が終了したことを表示する。

### Taskを管理する

Taskは必ず1つのRoomに属する。Taskを登録、編集、削除し、未完了・完了を切り替える。完了数と進捗率をRoomホームとRoom別アルバムに表示する。

`due_date`は任意とする。設定する場合だけ、紐づくRoomの開始日から終了日までの範囲に収める。Room期間外の日付は、フォーム、ORM経由、直接DB操作のいずれでも保存できない。

### SHUNKAN-logと写真

今を残す画面で、そのときの出来事や気持ちをSHUNKAN-logとして残す。通常ログの発生日時は紐づくRoom期間内にする。Task完了時には、任意でそのTaskに紐づくSHUNKAN-logを作成できる。

写真はMomentLogに紐付ける。JPEG / PNG / WebP / GIF形式、1枚10MB以下、MomentLog 1件あたり最大3枚とする。許可形式以外のファイル、壊れた画像、約4,000万画素を超える極端に大きな画像は受け付けない。保存時は元の縦横比を保って長辺1920px以下へ縮小・最適化し、GIFアニメーションは維持する。アルバムでは画像の向きや縦横比にかかわらず、中央基準で正方形にトリミングして同じ大きさで表示する。写真には本文とは別に短いひとことを添えられる。これは他ユーザーが書くコメント機能ではない。

### カテゴリ

MVPでは、カテゴリはRoom内の選択肢として使う。

- TaskとMomentLogは、同じRoomのCategoryだけを選べる。
- カテゴリの作成・編集・削除画面はMVPに含めない。
- 初期カテゴリ・デモカテゴリはseedまたはRoom作成時の初期データで用意する。
- 利用者がカテゴリ管理できるようにする場合は、別Issueを作成してから扱う。

### Room別アルバム

Room別アルバムでは、同じRoomの完了Task、SHUNKAN-log、写真、写真へのひとこと、達成数、進捗率を確認する。

## Room状態と操作可否

| 状態 | Task | 通常SHUNKAN-log | Photo / caption | Room設定 | 閲覧 |
| --- | --- | --- | --- | --- | --- |
| 開催中 | 作成・編集・削除・完了切替可 | 作成・編集・削除可 | 追加・編集・削除可 | MVPで提供する操作だけ可 | 可 |
| 終了後・Additional未実装 | 不可 | 不可 | 不可 | 不可 | 可 |
| 振り返り期間・Additional実装時 | 不可 | 不可 | 不可 | 不可 | reflection新規投稿だけ可 |
| 振り返り期限後 | 不可 | 不可 | 不可 | 不可 | 可 |
| アーカイブ | 不可 | 不可 | 不可 | 不可 | 可 |

UIで操作を隠すだけでなく、直接URLやPOSTでもサーバー側で拒否することを受入条件とする。Room状態の操作制御は[#59](https://github.com/KDGT2026-Summer-Techjam/SHUNKAN/issues/59)の方針に従う。

## Additional機能

### 終了後の振り返りログ

終了後の振り返りログはAdditionalであり、Must完了後にのみ着手する。実装する場合は、Room終了後から`reflection_deadline_at`まで、`entry_type=reflection`の新規投稿だけを許可する。既存のTask、通常SHUNKAN-log、Photo、caption、Room設定は変更できない。

Additional未実装時、終了済みRoomは閲覧専用とする。

## アーカイブ

MVPでは、利用者向けのアーカイブ・復元画面は実装対象外とする。

- `is_archived`は将来の一覧整理に備えた状態として保持する。
- アーカイブ済みRoomは閲覧専用。
- 利用者がアーカイブ・復元する操作をMVPへ入れる場合は、操作仕様と専用Issueを追加する。

## 画面設計

| 画面 | URL | 目的 | 主な表示・操作 |
| --- | --- | --- | --- |
| 登録・ログイン | `/accounts/signup/`、`/accounts/login/` | 自分のデータで使い始める | 登録、ログイン、ログアウト |
| Room一覧 | `/rooms/` | 期間を選ぶ・作る | 自分のRoom一覧、作成、切替 |
| Roomホーム | `/rooms/<room_id>/` | 選択中Roomの現在地を知る | 秒単位カウントダウン、完了数、進捗率、次のTask、最新のSHUNKAN-log |
| 今を残す | `/rooms/<room_id>/moments/new/` | 瞬間を記録する | 本文、カテゴリ、発生日時、写真、写真へのひとこと |
| Task | `/rooms/<room_id>/tasks/` | やりたいことを管理する | Task登録・編集・削除、完了操作 |
| Room別アルバム | `/rooms/<room_id>/album/` | 期間を振り返る | 完了Task、SHUNKAN-log、写真、写真へのひとこと、達成数、進捗率 |

## データ設計

### User（利用者）

Django標準の認証ユーザーを使う。独自のパスワード列を持つテーブルは作らない。

### Room

| 項目 | 型・制約 | 説明 |
| --- | --- | --- |
| owner | Userへの参照、必須 | 作成者。自分以外のRoomは見えない |
| name | 文字列、1〜50文字、必須 | 例：2026 夏、文化祭まで |
| starts_at | 日時、必須 | 期間の開始日時 |
| ends_at | 日時、必須、`starts_at`より後 | カウントダウンの終了日時 |
| reflection_deadline_at | 日時、任意 | Additional実装時の振り返り期限 |
| is_archived | 真偽値、初期値false | 将来の一覧整理に備えた状態 |

### Category

| 項目 | 型・制約 | 説明 |
| --- | --- | --- |
| room | Roomへの参照、必須 | どのRoom内のカテゴリか |
| name | 文字列、1〜30文字、必須 | 例：花火、グルメ、準備 |
| color | 文字列、任意 | 画面で使う色 |

### Task

| 項目 | 型・制約 | 説明 |
| --- | --- | --- |
| room | Roomへの参照、必須 | どの期間のTaskか |
| title | 文字列、1〜100文字、必須 | やりたいこと |
| category | Categoryへの参照、任意 | 同じRoom内の分類のみ選択可 |
| due_date | 日付、任意。設定時はRoom期間内 | 実行したい日 |
| is_completed | 真偽値、初期値false | 完了状態 |
| completed_at | 日時、任意 | 完了にした日時 |

### MomentLog（SHUNKAN-log）

| 項目 | 型・制約 | 説明 |
| --- | --- | --- |
| room | Roomへの参照、必須 | どの期間の記録か |
| body | 文字列、1〜280文字、必須 | 残したい出来事・気持ち |
| entry_type | 選択式、初期値`moment` | 通常ログまたはAdditionalの`reflection` |
| category | Categoryへの参照、任意 | 同じRoom内の分類のみ選択可 |
| occurred_at | 日時、必須 | 瞬間があった日時 |
| task | Taskへの任意参照 | 同じRoomのTaskだけを選択可 |

`entry_type=moment`の場合、`occurred_at`はRoom期間内にする。`entry_type=reflection`はAdditional実装時だけ、Room終了後から`reflection_deadline_at`まで新規投稿できる。

### Photo

| 項目 | 型・制約 | 説明 |
| --- | --- | --- |
| moment_log | MomentLogへの参照、必須 | 紐づくSHUNKAN-log |
| image | JPEG / PNG / WebP / GIF、必須、1ファイル10MB以下 | 元の縦横比を保って長辺1920px以下へ縮小・最適化し、ファイル本体はストレージに置く |
| caption | 文字列、任意、1〜140文字 | 写真へのひとこと |
| sort_order | 整数、初期値0 | 同じ記録内の表示順 |

SHUNKAN-log 1件には写真を最大3枚まで添付できる。保存ファイルの縦横比は維持し、画面表示ではCSSの`aspect-ratio: 1`と`object-fit: cover`を使って正方形に統一する。Room境界、期間、写真3枚上限はPostgreSQLのDBレベルでも守る方針とし、[#60](https://github.com/KDGT2026-Summer-Techjam/SHUNKAN/issues/60)に従う。

## MVP外・将来機能

- 他人のTask・SHUNKAN-logの閲覧
- 公開アルバム、共有URL、共同編集
- SNSへの投稿・連携
- 他ユーザーからのコメント、いいね、フォロー
- プッシュ通知・メール通知
- EXIFからの撮影日時自動取得、位置情報の取得・表示
- 動画アップロード

## 受入条件

1. ログインした利用者は、自分のRoomだけを作成・閲覧・編集できる。
2. Roomホームを開くと、そのRoomの終了日時までの残り時間が秒単位で更新される。
3. 2026 夏とTechJam 2026を同時に持て、切替時にカウントダウンとデータが切り替わる。終了日時はそれぞれ2026-08-31 23:59:59 JST、2026-08-28 18:00:00 JSTとする。
4. `due_date`は未設定で保存でき、設定時はRoom期間内に限る。フォーム、ORM、直接DB操作のいずれでもRoom期間外の日付を保存できない。
5. TaskとMomentLogは同じRoomのCategoryだけを選べる。
6. 写真はMomentLogに紐付き、JPEG / PNG / WebP / GIF形式・1枚10MB以下・最大3枚までとする。保存時は元の縦横比を保って長辺1920px以下へ縮小・最適化し、GIFアニメーションを維持する。アルバムではすべて正方形かつ同じ大きさで表示し、写真へのひとことを扱える。
7. 開催中以外のRoomでは、UIだけでなく直接URLやPOSTでも、Task、通常SHUNKAN-log、Photo / caption、Room設定の変更を拒否する。
8. Additional実装時だけ振り返り期間のreflection新規投稿を許可し、Additional未実装時の終了済みRoomは閲覧専用にする。
9. Room境界、期間、写真3枚上限をPostgreSQLのDBレベルでも保証する。
