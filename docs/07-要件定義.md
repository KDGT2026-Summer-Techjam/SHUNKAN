# SHUNKAN 要件定義

## 目的

SHUNKAN は、夏の終わりまでに「やりたいこと」と「今しかない瞬間」を自分のために残し、季節を楽しめた実感をつくる個人利用の Web アプリです。

## MVPの前提

- 利用者は1人です。ログイン、ユーザー登録、他ユーザーの閲覧は実装しません。
- すべてのデータは、利用者本人が使うアプリ内のデータベースに保存します。
- 夏の終了日時は **2026年8月31日 23:59:59（日本時間）** に固定します。
- 共有・公開・SNS投稿・共同編集・通知・写真アップロードはMVP外です。

## Must機能

### 秒単位カウントダウン

ホームで夏の終了日時までの残り **日・時・分・秒** を1秒ごとに更新して表示します。終了後はカウントダウンを `00日 00:00:00` に固定し、「夏は終了しました」と表示します。

### 旬の瞬間を残す

「今を残す」画面で、そのときの出来事や気持ちを短い文章として記録します。記録時刻は現在時刻を初期値とし、後から変更できます。瞬間ログは夏のアルバムで新しい順に振り返れます。

### 夏タスクを管理する

タスクを登録し、未完了・完了を切り替えます。完了数と進捗率をホームと夏のアルバムに表示します。

## 画面設計

| 画面 | URL | 目的 | 主な表示・操作 |
| --- | --- | --- | --- |
| ホーム | `/` | 夏の残り時間と現在地を知る | 秒単位カウントダウン、完了数、進捗率、次のタスク、最新の瞬間ログ |
| 今を残す | `/moments/new/` | 旬の瞬間を記録する | 本文・カテゴリ・発生日時の入力、保存 |
| タスク | `/tasks/` | やりたいことを管理する | 未完了/完了の切替、タスク登録・編集、完了操作 |
| 夏のアルバム | `/album/` | 夏を振り返る | 完了タスク、瞬間ログ、達成数、進捗率 |

スマートフォン幅を基準にし、ホームではカウントダウン・進捗・次のタスク・最新の瞬間を別々のカードとして表示します。一覧では、タスクと瞬間ログを1件ずつカードとして表示します。

## データ設計

### Task（タスク）

| 項目 | 型・制約 | 説明 |
| --- | --- | --- |
| `title` | 文字列、1〜100文字、必須 | やりたいこと |
| `category` | 選択式、必須 | イベント / レジャー・グルメ / 自然・癒し / その他 |
| `due_date` | 日付、必須、2026-08-31以前 | 実行したい日 |
| `is_completed` | 真偽値、初期値`false` | 完了状態 |
| `completed_at` | 日時、任意 | 完了にした日時 |
| `created_at` | 日時、自動 | 登録日時 |
| `updated_at` | 日時、自動更新 | 最終更新日時 |

### MomentLog（瞬間ログ）

| 項目 | 型・制約 | 説明 |
| --- | --- | --- |
| `body` | 文字列、1〜280文字、必須 | 残したい出来事・気持ち |
| `category` | 選択式、必須 | 食べた / 見た / 行った / 感じた / その他 |
| `occurred_at` | 日時、必須、初期値は現在時刻 | 瞬間があった日時 |
| `task` | Taskへの任意参照 | 関連するタスク。未指定でも保存できる |
| `created_at` | 日時、自動 | 登録日時 |
| `updated_at` | 日時、自動更新 | 最終更新日時 |

## MVP外の共有機能

次の機能は今回実装しません。

- アカウント登録、ログイン、複数ユーザー対応
- 他人のタスク・瞬間ログの閲覧
- 公開アルバム、共有URL、共同編集
- SNSへの投稿・連携
- コメント、いいね、フォロー
- プッシュ通知・メール通知
- 写真・動画アップロード

共有機能を追加する場合は、認証・公開範囲・削除・通報・個人情報保護を別途設計してから実装します。

## 受入条件

1. ホームを開くと、2026年8月31日23:59:59までの残り時間が秒単位で更新される。
2. 瞬間ログを登録すると、夏のアルバムで新しい順に確認できる。
3. 期限が未入力または2026年9月1日以降のタスクは保存できない。
4. タスクを完了にすると、完了数と進捗率が更新される。
5. 他ユーザーとの共有・公開に関する操作や画面は表示されない。
