# 旬間 (SHUNKAN) 要件定義

## 目的

旬間 (SHUNKAN) は、利用者が自分で決めた今だけの期間をルームとして作り、やりたいこと、達成したこと、その瞬間の記録、写真を振り返るスマートフォン向けの個人利用 Web アプリです。

最初のデモでは、2026 夏と TechJam 2026 の2ルームを用意します。将来は文化祭まで、旅行までなど、利用者の体感に合う期間でも使えます。

## MVPの前提

- 利用者は登録・ログインして使い、自分のルームとデータだけを閲覧・編集する。
- ルームは個人用であり、共有、公開、共同編集は行わない。
- 各ルームは名前、開始日時、終了日時を持ち、終了日時までを秒単位で数える。
- TechJam 2026 の終了日時は、2026年8月28日18:00（日本時間）とする。
- 写真アップロードは実装対象とする。EXIFから撮影日時や位置情報を読む機能は将来対象とする。

## Must機能

### ログインとルーム

利用者はユーザー登録、ログイン、ログアウトを行う。ログイン後は、自分が作成したルームだけを操作できる。

ルームには、少なくとも次を設定する。

- ルーム名。例：2026 夏、文化祭まで
- 開始日時
- 終了日時

### 秒単位カウントダウン

選択中ルームの終了日時までの残り日、時、分、秒を1秒ごとに更新して表示する。終了後は 00日 00:00:00 に固定し、この期間は終了しましたと表示する。

ルームを切り替えると、そのルーム固有の終了日時、進捗、タスク、記録を表示する。

### タスクを管理する

タスクは必ず1つのルームに属する。タスクを登録し、未完了・完了を切り替える。完了数と進捗率をルームホームとルームのアルバムに表示する。

タスクの期限は、紐づくルームの開始日から終了日までに設定する。

### 旬の瞬間を残す

今を残す画面で、そのときの出来事や気持ちを短い文章として記録する。記録時刻は現在時刻を初期値とし、後から変更できる。通常ログの発生日時は紐づくルーム期間内にする。

瞬間ログには0枚以上の写真を添えられる。タスク完了時にも、任意でそのタスクに紐づく瞬間ログを作成し、写真やひとことを残せる。瞬間ログはルームのアルバムで新しい順に振り返れる。

### 写真へのひとこと

写真には、瞬間ログ本文とは別に写真ごとの短いコメントを添えられる。

- 瞬間ログ本文：その場で起きた出来事や気持ち
- 写真へのひとこと：写っているものや、写真を見返したときに読みたい一言

これは他ユーザーが書くコメント機能ではない。ルームを作成した本人だけが入力・編集する。

## Additional機能

### 終了後の振り返りログ

ルーム終了後も、限られた期間だけ振り返りログを投稿できる。

- 通常のタスク、通常の瞬間ログはルーム終了後に追加できない。
- 振り返りログは、終了後に表示する この期間を振り返る から投稿する。
- 振り返りログは通常ログと区別してアルバムに表示する。
- 振り返りログの投稿期限は、ルームの reflection_deadline_at までにする。
- 初期値は、ルーム終了日時から7日後とする。

この機能はMust完了後に着手する。時間が足りなければ、終了後のルームは閲覧専用にする。

## 画面設計

| 画面 | URL | 目的 | 主な表示・操作 |
| --- | --- | --- | --- |
| 登録・ログイン | /accounts/signup/、/accounts/login/ | 自分のデータで使い始める | 登録、ログイン、ログアウト |
| ルーム一覧 | /rooms/ | 期間を選ぶ・作る | 自分のルーム一覧、作成、切替 |
| ルームホーム | /rooms/<room_id>/ | 選択中ルームの現在地を知る | 秒単位カウントダウン、完了数、進捗率、次のタスク、最新の瞬間ログ |
| 今を残す | /rooms/<room_id>/moments/new/ | 旬の瞬間を記録する | 本文、カテゴリ、発生日時、写真、写真へのひとこと、保存 |
| タスク | /rooms/<room_id>/tasks/ | やりたいことを管理する | 未完了/完了の切替、タスク登録・編集、完了操作 |
| ルームのアルバム | /rooms/<room_id>/album/ | 期間を振り返る | 完了タスク、瞬間ログ、写真、写真へのひとこと、達成数、進捗率 |

スマートフォン幅を基準にし、ルームホームではカウントダウン・進捗・次のタスク・最新の瞬間を別々のカードとして表示する。

## データ設計

### User（利用者）

Django標準の認証ユーザーを使う。独自のパスワード列を持つテーブルは作らない。

### Room（ルーム）

| 項目 | 型・制約 | 説明 |
| --- | --- | --- |
| owner | Userへの参照、必須 | 作成者。自分以外のルームは見えない |
| name | 文字列、1〜50文字、必須 | 例：2026 夏、文化祭まで |
| starts_at | 日時、必須 | 期間の開始日時 |
| ends_at | 日時、必須、starts_atより後 | カウントダウンの終了日時 |
| reflection_deadline_at | 日時、任意 | 終了後に振り返りログを投稿できる期限 |
| is_archived | 真偽値、初期値false | 終わったルームを一覧から隠す状態 |
| created_at | 日時、自動 | 登録日時 |
| updated_at | 日時、自動更新 | 最終更新日時 |

### Category（カテゴリ）

| 項目 | 型・制約 | 説明 |
| --- | --- | --- |
| room | Roomへの参照、必須 | どのルーム内のカテゴリか |
| name | 文字列、1〜30文字、必須 | 例：花火、グルメ、準備 |
| color | 文字列、任意 | 画面で使う色。未設定でもよい |
| created_at | 日時、自動 | 登録日時 |

### Task（タスク）

| 項目 | 型・制約 | 説明 |
| --- | --- | --- |
| room | Roomへの参照、必須 | どの期間のタスクか |
| title | 文字列、1〜100文字、必須 | やりたいこと |
| category | Categoryへの参照、任意 | ルーム内の分類 |
| due_date | 日付、必須、ルーム期間内 | 実行したい日 |
| is_completed | 真偽値、初期値false | 完了状態 |
| completed_at | 日時、任意 | 完了にした日時 |
| created_at | 日時、自動 | 登録日時 |
| updated_at | 日時、自動更新 | 最終更新日時 |

### MomentLog（瞬間ログ）

| 項目 | 型・制約 | 説明 |
| --- | --- | --- |
| room | Roomへの参照、必須 | どの期間の記録か |
| body | 文字列、1〜280文字、必須 | 残したい出来事・気持ち |
| entry_type | 選択式、初期値moment | 通常ログまたは終了後のreflection |
| category | Categoryへの参照、任意 | ルーム内の分類 |
| occurred_at | 日時、必須 | 瞬間があった日時 |
| task | Taskへの任意参照 | 関連するタスク。未指定でも保存できる |
| created_at | 日時、自動 | 登録日時 |
| updated_at | 日時、自動更新 | 最終更新日時 |

entry_type が moment の場合、occurred_at はルーム期間内にする。entry_type が reflection の場合だけ、ルーム終了後から reflection_deadline_at まで投稿でき、occurred_at は投稿日時を使う。

### Photo（写真）

| 項目 | 型・制約 | 説明 |
| --- | --- | --- |
| moment_log | MomentLogへの参照、必須 | 紐づく瞬間ログ |
| image | 画像ファイル、必須 | ファイル本体はDBではなくストレージに置く |
| caption | 文字列、任意、1〜140文字 | 写真へのひとこと |
| sort_order | 整数、初期値0 | 同じ記録内の表示順 |
| created_at | 日時、自動 | アップロード日時 |

将来、EXIFから得た撮影日時を captured_at に保存できる。撮影日時の出どころは captured_at_source（exif / manual / unknown）で区別する。GPS座標・端末名などの生メタデータは、利用者の明示的な同意なしには保存・表示しない。

## MVP外・将来機能

- 他人のタスク・瞬間ログの閲覧
- 公開アルバム、共有URL、共同編集
- SNSへの投稿・連携
- 他ユーザーからのコメント、いいね、フォロー
- プッシュ通知・メール通知
- EXIFからの撮影日時自動取得、位置情報の取得・表示
- 動画アップロード

## 受入条件

1. ログインした利用者は、自分のルームだけを作成・閲覧・編集できる。
2. ルームホームを開くと、そのルームの終了日時までの残り時間が秒単位で更新される。
3. 2026 夏と TechJam 2026 を同時に持て、ルームを切り替えるとカウントダウンとデータが切り替わる。
4. TechJam 2026 のカウントダウンは2026年8月28日18:00（日本時間）に終了する。
5. 瞬間ログを登録すると、そのルームのアルバムで新しい順に確認できる。写真と写真へのひとことを添えた場合は両方を表示する。
6. ルーム期間外の日付を、通常タスクの期限または通常ログの発生日時として保存できない。
7. タスクを完了にすると、同じルームの完了数と進捗率が更新される。
8. Mustが未完成の場合、終了後のルームは閲覧専用にする。Additionalを実装した場合だけ振り返りログを投稿できる。
9. 他ユーザーとの共有・公開に関する操作や画面は表示されない。
